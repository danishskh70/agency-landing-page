# Agency-landing-page

A fully responsive marketing agency landing page built as a Bootstrap 5 practice project.

## About

This project is a multi-section landing page for a fictional marketing agency called **Potato Agency**. The goal was to practice real-world frontend structure — not just building components but organizing them properly with a clean separation between HTML and CSS.

## What I Built

- **Hero** — headline, description, CTA buttons, and a live transaction chart card
- **Features** — two-column card layout with active user stats and data visualizations
- **Pricing** — pricing card alongside feature highlight boxes
- **Testimonials** — quote section with client attribution
- **Founder** — founder spotlight card with image and quote
- **CTA** — call-to-action section
- **Footer** — newsletter signup, office info, and social links

## What I Practiced

- Structuring a full landing page from scratch using **Bootstrap 5**
- Replacing all inline and internal styles with a single **external CSS file**
- Using **CSS custom properties** to manage brand colors and layout tokens
- Building a `.page-container` system so every section has consistent alignment
- Writing **responsive layouts** using Bootstrap's grid and utility classes
- Using `clamp()` for fluid typography that scales across screen sizes
- Drawing **SVG charts** without any JavaScript library
